# Doorbook

UK resident web app for booking fire door installation appointments.

## Features
- Postcode lookup using free open data from postcodes.io (no API key needed)
- House number entry
- Select available time slots over the next 7 days
- Collect contact details with GDPR consent checkbox
- Simple privacy notice based on ICO guidance

## Brand
- Paper background: #F4F1EB
- Door green: #1C453B

## How to use
Open `index.html` in a browser. For local development you can use any static server.

This is a frontend prototype. A production version would need a secure backend for storing bookings, email notifications, and full GDPR compliance processes (data subject access requests, retention schedules, etc.).

## Sources
- Postcode data: postcodes.io (open data from ONS and Ordnance Survey)
- Privacy notice principles: Information Commissioner's Office (ICO) guidance on the right to be informed under UK GDPR
